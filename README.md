# MYSKME自鸣棋

MYSKME × 王老师（Mr. Wang）· **神秘策略肉鸽自走棋** —— 年轻但不幼稚；单人闯关可独玩，课堂模式可围桌，扫码 / 投屏即用。

学生用答题赚来的铸币，三选一征募《狼先生与他的学生们》编年史学员组建军团；每幕演武自动演算对战，全班围观——棋子自己开打，故曰**自鸣**。答题决定经济，构筑与站位决定胜负，命运事件决定谁也别想躺赢。

**正式地址：** https://zimingqi.myskme.com/
**灾备地址：** https://myskme.github.io/myskme-zimingqi/
**作品总目：** https://myskme.com/

## 核心循环（一节课一局 · 30–40 分钟 · 1–8 人（含 1 对 1 课堂））

```
开局点将（人人免费领一名学员）
   ↓
┌ 答题波（老师判定：答对+2 / 难题+3 / 抢答+1 / 答错喂暴走槽）
│    ↳ 幕初公示宿敌预告：本幕演武打谁，一开始就知道
├ 征募 · 三选一（落后者先选 · 3格备战席留牌转型 · 双卡合星 · 存币吃利息 · 棋位轨道按钮调站位）
├ 命运事件（20 张全局事件卡，对落后者更友好）
└ 演武 · 自动演算对战（胜者夺王座分，败者领复仇火种）
   × 三幕（谷地雾晨 → 断云之上 → 黑域门前）→ 加冕 + 战报卡 PNG
```

答错喂满「暴走槽」会触发**叶王乱入**：本幕演武取消，全员各自迎击黑域侵攻——PvP 里嵌一段全班共同的 PvE 变奏。

## 特性

- **单文件 `index.html`**，离线可用；美术资源走 `assets/` 映射层，缺图自动回退字形徽章
- **真实回响战书**：结算页把本局真实军团编码进分享链接，对方无需登录即可接战；排行榜不填充虚拟玩家，空赛季改用个人门槛与系统守关局承接
- **跨平台发布资源**：一枚克制的黑曜石棋子母版统一派生 PWA、iOS AppIcon、微信小游戏图标、5:4 分享卡与 Open Graph 封面，见 `assets/platform-20260809/`
- 41 名编年史学员 + 2 名自鸣棋本地单位（新入棋：子鱼、克、宸、铭、钧、杰；六人立绘已同步至 v2，钧采用成熟完整站姿）+ **双轴羁绊**（星象四象：厚土载物/疾风借势/烈焰同燃/潮汐同悲 × 跨象打法；十二星座归四象，另有四象单环相克「土掩水→水灭火→火灼风→风蚀土」，阵营为剧情归属）+ 22 遗物 + 25 命运事件（3 张为鎏金狂宴专属）
- **四象星图 · 羁绊图鉴**：手机按象切换、桌面四象同屏，可按名字或星座定位学员；四象相克、六种打法与八组秘契分三层查阅。自动资产管线同时派生 2400 × 3000 高清收藏图、1200 × 1500 传播图、600 × 750 缩略图与结构化 `atlas-data.json`，可复用到 Hub、编年史、微信和未来 iOS 版本
- **三格备战席**：候补不上场、不激活羁绊，但与军团同名牌共同合星；军团满员后新成员自动进入候补，可根据宿敌情报临场换阵，旧 `v1` 存档自动补空席
- 羁绊效果在征募页常驻对账并于开战时播报；锋锐首击、坚韧复起、制御压速等不再只亮图标而缺少反馈
- 正典搭档重构：增／浩组成「谷地双壁」；梓／狼先生均达到 ★2 后觉醒终极羁绊「灯火相承」
- 六人小队联动：子鱼与海/麒/浩组成「四海同光」；克/宸组成「画像与弓」；铭/钧/杰组成「三影」。这些只给小幅护盾或速度，四象与打法仍是主构筑轴
- **布衣结义（弱卡流派）**：把 N·R 低稀有卡合星到 ★★ 及以上才计数，凑 3 名成阵、5 名满档——配合低稀有最陡的三星倍率，肯投入的平民军团可与 SSR/UR 豪阵掰腕子
- **鎏金狂宴（多人欢乐风格）**：开局 8 币、答题加币翻倍、4 币生 1 息（封顶 5）、牌力半价、刷新 1 币、军团上限全程 +1、开席人人随机一件遗物，另有 3 张狂宴专属命运事件；适合期末与奖励课，欢乐局不计课堂榜
- **加冕称号**：终局每人一枚按打法授予的四字称号（布衣封侯/答题先锋/鎏金巨富……），全班不重样并印上战报卡；开屏语录按日轮换、节日有专属签，战斗二倍速偏好跨局记忆
- **MYSKME 通用游戏图标系统**：43 枚原创 24px SVG，攻击／生命／速度／铸币／王座分、站位、出售、撤销、倍速，以及四象、狼牙悬赏、影军回响都不再依赖 Emoji 或系统图形字体；同一套资源可跨游戏复用
- 防滚雪球三件套：落后者先选卡、复仇火种、事件权重向落后者倾斜
- 黑域单位高风险高收益（航：全场最高攻，但每幕吞你 1 铸币——"自愿戴上锁"的机制化）
- 战报卡 Canvas 可直接调用系统分享并附带回响战书，也可导出 PNG；localStorage 断电续局
- 老师调节阀：幕数 / 暴走阈值 / 事件开关；全程单屏投屏，题在老师手里

## 课堂提示

- 节奏慢的班：暴走阈值调 6，叶王来得更早，气氛立刻紧张
- 水平差距大：基础题多用「抢答 +1」，难题留给领先者
- 赶时间：开局选「两幕 · 快课」，战斗随时可二倍速 / 跳过

## 美术管线

`assets/` 内美术按生产清单管理，文件名与游戏内 `ART` 映射表一一对应。新批次放入版本子目录并通过映射切换，不覆盖旧原图；缺图自动回退字形徽章。本地 file:// 打开时战报卡不嵌立绘（画布安全限制），线上部署后正常。发布图标刻意只保留一枚棋子、一个日蚀圆盘与黑金青三色，避免角色海报缩成图标后产生的堆料感。

系统图标使用独立 UI_ICON_VER。37 枚首批资产保留在 `assets/ui-icons-20260714/`，43 枚完整新版位于 `assets/ui-icons-20260714b/`，没有同名覆盖旧目录。游戏本体为保证课堂断网与 file:// 稳定，使用同源内联 SVG；新版资产目录同时提供 sprite、43 个独立 SVG、manifest 与预览，方便其他作品直接复用。

## 技术

纯 HTML/CSS/JS、零依赖，核心课堂玩法可完全离线；只有世界回廊、影军与课堂榜在用户主动使用时联网。
联网统一走 `https://myskme.com/api/game` 品牌网关，再固定转发到原
Cloudflare Worker + D1；不迁库、不双写。战斗演算核心为纯函数
（`/*SIM-BEGIN*/`…`/*SIM-END*/` 标记段），可脱离 DOM 单测。

正式入口由 GitHub Pages + `zimingqi.myskme.com` 强制 HTTPS 承载。Service Worker 采用
“0.9 秒缓存先开、4.5 秒后台止损、资源按需缓存”的弱网策略；待上传成绩延后到首屏空闲期，
并在离线恢复联网时自动补传。影军/名匠/世界榜统一使用带超时的品牌网关请求，真实音效下载
限制为三路并发，避免首手势瞬间同时拉取 24 个小文件。详细发布边界见 `NETWORK-DEPLOYMENT.md`。

发布前运行 `npm run selftest`、`npm run selftest:pwa`、`npm run qa:network` 与 `npm run verify:release`；其中网络专项使用本地模拟网关，验证 simple POST、弱网留档、并发补传不吞高分、恢复重试及快速切榜不被旧响应反盖，不会污染正式排行榜。还可运行 `npm run qa:strategy` 验证候补/羁绊/存档/双视口，运行 `npm run qa:balance` 做关键羁绊连续强度扫描。图鉴资料变更后先运行 `npm run build:atlas` 重建高清图，再运行 `npm run qa:atlas` 核对 43 人、四象、羁绊、秘契与手机/桌面布局。
